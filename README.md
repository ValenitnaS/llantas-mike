# llantas-mike

Página web de Llantas Mike, taller dedicado a la reparación,
restauración y pintura de llantas en La Florida, Santiago de Chile.

Este es mi primer sitio web publicado. Lo desarrollé como un
proyecto de aprendizaje.

## 🌐 Visitar la página

https://valenitnas.github.io/llantas-mike/

## ✨ Características

- Diseño adaptable a computadores y celulares.
- Carrusel de fotografías con opción de pausa.
- Información sobre los servicios del taller.
- Galería con visor de imágenes y botón para cerrar.
- Formulario que prepara una consulta para WhatsApp.
- Preguntas frecuentes.
- Dirección, horarios y enlace a Google Maps.
- Favicon con el logo del taller.

## 🛠️ Tecnologías utilizadas

- HTML: estructura y contenido.
- CSS: diseño y adaptación a distintos tamaños de pantalla.
- JavaScript: menú, carrusel, galería y formulario.
- GitHub Pages: publicación del sitio.
- Visual Studio Code: edición del código.

## 📁 Organización del proyecto

- `index.html`: contenido principal.
- `styles.css`: estilos de la página.
- `script.js`: funcionalidades interactivas.
- `img/`: logo y fotografías.

## 💻 Abrir el proyecto localmente

1. Descargar el repositorio y descomprimirlo.
2. Mantener los archivos y la carpeta `img` juntos.
3. Abrir `index.html` en un navegador.

No requiere instalación de dependencias ni una base de datos.

## 💬 Funcionamiento del formulario

El formulario prepara un mensaje y abre WhatsApp.
El visitante debe enviarlo para iniciar la consulta y puede
adjuntar las fotografías en esa conversación.

La página no guarda las solicitudes en una base de datos propia.
Enviar una consulta no confirma una cita.
